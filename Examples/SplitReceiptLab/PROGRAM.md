# Split Receipt Lab program

Goal: improve a local receipt pipeline without regressing protected restaurant-style baselines.

## Rules

- mutate only bounded strategy surfaces
- run the fixed receipt scenario set
- keep only score improvements or simpler equally-good behavior
- revert regressions immediately
- do not widen claims beyond the narrow slice under evaluation
- use Cupertino for exact Apple framework documentation when API questions arise

## Primary score dimensions

- item fidelity
- subtotal and total fidelity
- truthful abstention
- review-before-save correctness
